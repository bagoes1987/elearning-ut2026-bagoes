## 📚 8 Menu Interaktif di Setiap Pertemuan Tutorial (Sesi 1 s/d 8)

Setiap pertemuan dilengkapi dengan 8 menu terstruktur sesuai standar mutu pembelajaran Universitas Terbuka:
1. **👥 Pembagian Kelompok**: Pembagian kelompok kolaboratif dengan nama dan NIM mahasiswa asli dari pangkalan data, penunjukan koordinator/ketua, serta topik diskusi spesifik.
2. **📑 RAT / SAT**: Rancangan Aktivitas Tutorial & Satuan Aktivitas Tutorial resmi UT, Capaian Pembelajaran (CPMK & Sub-CPMK), serta alokasi waktu 120 menit (Pendahuluan, Inti, Penutup).
3. **💡 Pertanyaan Pemantik**: Pertanyaan pemantik daya kritis (HOTS) dari Tutor dan forum diskusi interaktif.
4. **📖 Materi**: Rangkuman inisiasi konsep inti, rujukan Buku Materi Pokok (BMP) digital UT, dan slide presentasi PPT.
5. **🎥 Video Pembelajaran**: Media pembelajaran audiovisual terintegrasi beserta catatan konsep kunci.
6. **📝 LKPD**: Lembar Kerja Mahasiswa berbasis studi kasus nyata di sekolah dasar, formulir jawaban, dan upload berkas tugas (PDF/Word/Foto).
7. **📊 Asesmen**: Kuis formatif pilihan ganda dengan penilaian otomatis instan dan pembahasan kunci jawaban, serta penugasan **Tugas Tutorial Wajib (TTM 1, 2, 3)** pada Sesi 3, 5, dan 7.
8. **💭 Refleksi**: Lembar refleksi mandiri model 3-2-1 dan umpan balik langsung kepada Tutor Pengampu.

## 🔒 Sistem Keamanan & Autentikasi Mahasiswa

- **Username**: Email Kampus (misal: `860080512@ecampus.ut.ac.id`) atau NIM.
- **Password**: NIM Mahasiswa.
- **Gated Access**: Rangkaian 8 tutorial dan seluruh modul materi terkunci rapat sebelum login.
- **Class-Based Authorization**: Mahasiswa hanya dapat mengakses rombel yang dikontraknya (mahasiswa 5A hanya dapat membuka kelas 5A, dst).
- **Tutor Master Access**: Akun Tutor dapat memantau dan mengelola seluruh rombel dan data mahasiswa.

## 🚀 Cara Menjalankan Secara Lokal

1. Buka terminal di direktori proyek:
   ```bash
   python -m http.server 8000
   ```
2. Buka browser pada alamat:
   ```
   http://localhost:8000/
   ```

## 🌐 Publikasi Online (GitHub Pages)

Proyek ini siap di-deploy langsung menggunakan **GitHub Pages**:
1. Masuk ke tab **Settings** pada repositori GitHub: `https://github.com/bagoes1987/elearning-ut2026-bagoes`
2. Buka menu **Pages** (di sidebar kiri).
3. Pada bagian **Build and deployment**, pilih Source: **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Situs web Anda akan aktif secara online di: `https://bagoes1987.github.io/elearning-ut2026-bagoes/`
